# International Rhabdoid Tumor Consortium (IRTC)

An informal collaboration space for pediatric neuro-oncology investigators working on
atypical teratoid/rhabdoid tumor (AT/RT).

- `index.html` — the site
- `data/` — research feeds (PubMed, ClinicalTrials.gov, Europe PMC preprints, NIH RePORTER grants),
  refreshed every morning by `.github/workflows/refresh.yml`
- `scripts/` — the feed builders

Member features (sign-in, profiles, discussions, meetings, messages) are being moved to Supabase.
